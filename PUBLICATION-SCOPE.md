# Publication scope

16 October 2026 · repository authorized by the user: https://github.com/MIKEAA2020/arena-max--physics

## Included

Generated v2.1/v2.2 framework sources and OOXML documents; generated lineage notes/visualizers and assessments; verification scripts and logs; independent replica operators, exact/spectral/MPS/SMC code and numerical datasets; v33 source, report, diff and review package; the new transition-order plan, execution notes, resumable states and results.

The immutable A-1 manuscript/reviewer inputs and credential-free assessment are narrowly identified **supplied reproduction inputs**, not claimed as original agent creations. They support input hashes, source-diff reproduction and historical adjudication checks. The generated paper-only ZIP already contains the identified manuscript input and its provenance. The later method-request record is a paraphrase, not an invented verbatim transcript.

## Excluded or separated

- All `.git`, `.arena`, credential files, private configuration and tokens. No credential is included even if it was supplied as part of a user message.
- The general `uploads/` directory: unrelated raw source uploads are not generated deliverables.
- Bulk third-party PDFs, web downloads and downloaded Quran JSON corpora. Bibliographic/provenance references remain in the reports. The Quran lookup/download scripts are supplied separately; source corpora can be obtained on demand and keep their source rights.
- Installed dependencies, caches and other reproducible build output.

The original repository history and license are preserved. Retaining the license does not relicense quoted literature, translations or supplied manuscripts, nor establish ownership of those inputs.

## Scientific status

Completed process, converged optimizer, converged thermodynamic observable and proof are different statuses. Checkpoint files can contain partial optimizer states. The result ledger identifies nonconverged and budget-stopped cases; neither metadata nor a GitHub upload upgrades them to a phase verdict. Missing figure/SM, proof-audit obligations and author approval remain publication requirements independent of repository availability.

A pre-staging scanner checks exact locally supplied secret values and token/private-key patterns in every published file, including nested ZIP/OOXML/NPZ contents. It prints filenames/status only, never secret values. The scanner cannot retroactively revoke a token exposed elsewhere; the user should rotate the previously shared token after this operation.
